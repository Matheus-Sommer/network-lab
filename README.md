# network-lab

Laboratório desenvolvido durante o curso de Cibersegurança. 

## Conceitos

- Aprender endereçamento IPv4
- Configurar switches e roteadores Cisco
- Implementar roteamento estático
- Entender tabelas de roteamento
- Testar conectividade entre redes

## Tecnologias

- Cisco Packet Tracer
- IPv4
- Cisco IOS
- Static Routing

## Comandos estudados

- show ip interface brief
- show ip route
- ping
- ip address
- ip route
